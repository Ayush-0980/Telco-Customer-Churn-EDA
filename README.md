# Telco Customer Churn — EDA Notebook Suite

## Overview

This project performs Exploratory Data Analysis (EDA) on the IBM Telco Customer Churn dataset to uncover patterns affecting customer retention.

## Objectives

- Analyze customer demographics
- Identify churn drivers
- Perform customer segmentation
- Study revenue impact
- Suggest retention strategies

## Dataset

IBM Telco Customer Churn Dataset

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure

- Data Profiling
- Churn Driver Analysis
- Customer Segmentation
- Revenue Impact
- Retention Strategy

## Key Insights

- Month-to-month contracts show the highest churn.
- Electronic check users churn more frequently.
- Long-tenure customers have significantly lower churn.
- Fiber optic customers exhibit higher churn rates.

## Results

Actionable business recommendations were developed to reduce churn and improve customer retention.
